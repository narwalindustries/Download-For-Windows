How to Install

1

Download Installer

Click the Download for Windows button above to save AirLink_Setup.exe on your PC.

2

Run Setup

Double-click AirLink_Setup.exe to install AirLink and create Start Menu & Desktop shortcuts.

3

Connect & Transfer

Open AirLink on both Windows and Android, scan the QR code or tap your PC on radar, and start sharing.

Windows SmartScreen Tip: If Windows shows a "Windows protected your PC" popup while running the installer, click More info and then select Run anyway to proceed with the installation.
